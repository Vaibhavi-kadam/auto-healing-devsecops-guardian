
# Auto-Healing DevSecOps Guardian

## Project Overview

Auto-Healing DevSecOps Guardian is a Python-based project designed to monitor application health, detect security issues, and automate recovery actions.

## Project Objectives

- Monitor application health.
- Detect application failures.
- Identify basic security threats.
- Automate recovery actions.
- Generate monitoring logs and reports.

## Technologies Used

- Python
- Linux
- Docker
- Git & GitHub
- AWS
- DevSecOps
- CI/CD

## Project Status

Currently under development.
